시트 UI 캡처

도구형 챗봇 UI

JSON 이 든 시트를 업로드하면 행마다 아티팩트를 운영 챗봇 화면 그대로 렌더링합니다.

파일을 여기로 끌어다 놓으세요 구글시트에서 파일 > 다운로드로 받은 xlsx 또는 csv
샘플 파일 받기

쓰는 순서

  1. 구글시트에서 xlsx 또는 csv 로 내려받습니다.
  2. 이 화면에 업로드하면 행마다 아티팩트가 렌더링됩니다.
  3. Export 한 파일을 구글시트 파일 > 가져오기로 올립니다.

JSON 형식

{"type": "MESSAGES_SNAPSHOT",
 "messages": [ ... ]}

JSON 이 든 첫 열을 찾아 쓰고, 렌더링 결과는 그 바로 옆 열에 넣습니다.
